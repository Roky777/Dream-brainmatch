# Dream Brainmatch — Shape Friends

A standalone, portrait-first memory matching adventure with Sparky, featuring Grade 1 shape pairs (Round, Box, Cone, Cylinder) across three unlockable worlds: **Dream Meadow**, **Season Parade**, and **Neon Shape Lab**.

## Quick Start
Run `npm start` with Node 20+ and open <http://127.0.0.1:4178/>. No install or build step is needed. The root page immediately opens `/shape-friends/`, fully compatible with GitHub Pages hosting under a repository subpath.

## Testing & Quality Assurance
Run `npm test` to execute all 68 automated unit, gameplay, voice, and animation checks.
